# Notice

`dsh-repomix` is a bounded repository packer for DeepSeek Harness.

It is inspired by [Repomix](https://github.com/yamadashy/repomix); no source code is copied. The
implementation is a small independent XML/Markdown packer with its own skip list, caps, and tests.

It is not a full Repomix-compatible implementation and does not use a tokenizer.
